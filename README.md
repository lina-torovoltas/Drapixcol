# Drapixcol
![Language](https://img.shields.io/badge/language%20-%20Python-3776AB)
![License](https://img.shields.io/github/license/lina-torovoltas/Drapixcol)
![Version](https://img.shields.io/pypi/v/drapixcol)

Python library for procedural pixel-art generation and canvas drawing.

## Installation

```bash
pip install drapixcol
```

## Usage

Full documentation, including functions, colors, transparency constants, and directions, is available in [docs.md](./docs.md).</br>
Code examples demonstrating how to use the library can be found in the [examples](./examples/) folder.
